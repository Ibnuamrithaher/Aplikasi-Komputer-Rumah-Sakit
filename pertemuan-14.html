Cloud Storage & Kolaborasi Dokumen Online

CPMK-6: Mampu mengelola sistem penyimpanan awan dan kolaborasi dokumen online secara tim.

  • Memahami konsep dan manfaat cloud storage untuk RS
  • Mengatur hak akses dokumen dengan benar
  • Berkolaborasi real-time pada dokumen bersama

Senin pagi, Mira Dewanti — koordinator laporan RS Ananda Husada (fiktif) — panik. Laporan bulanan yang sudah ia kerjakan selama tiga hari tiba-tiba tidak bisa dibuka. Ternyata flashdisk tempat ia menyimpan file itu mengalami kerusakan fisik. Tidak ada backup. Laporan harus diserahkan ke Direktur pukul 10.00. Ia harus memulai dari nol dalam waktu dua jam. Seandainya ia menyimpan file di cloud...

Hari ini kita belajar cara menyimpan dokumen di cloud secara aman, mengatur siapa yang boleh melihat dan mengedit, serta berkolaborasi dalam tim tanpa saling menimpa pekerjaan satu sama lain.

☁️ Cloud storage bukan sekadar backup: Ini adalah cara kerja modern yang memungkinkan tim RS berkolaborasi dari mana saja dengan data yang selalu sinkron dan terlindungi.

Google Drive untuk Lingkungan RS

  • Kuota: 15 GB gratis (akun personal); Google Workspace for Education/Business bisa ratusan GB s.d. unlimited
  • Google Docs, Sheets, Slides: format native yang bisa diedit bersama real-time tanpa mengunduh
  • Shared Drive: folder bersama yang tetap ada meski pemilik akun keluar dari organisasi
  • Pencarian canggih: cari berdasarkan isi file, bukan hanya nama
  • Integrasi email: attachment Gmail bisa langsung disimpan ke Drive
Untuk RS: gunakan akun Google Workspace institusi, bukan akun Gmail pribadi, agar data tetap di bawah kendali RS saat staf keluar.

OneDrive untuk Lingkungan RS

  • Kuota: 5 GB gratis; Microsoft 365 (Office 365) hingga 1 TB per pengguna
  • Integrasi Office: Word, Excel, PowerPoint bisa disimpan dan dibuka langsung dari OneDrive tanpa konflik versi
  • SharePoint: platform kolaborasi dokumen tingkat enterprise untuk RS besar
  • Personal Vault: lapisan keamanan tambahan (verifikasi dua langkah) untuk file sangat sensitif
  • AutoSave: perubahan tersimpan otomatis setiap beberapa detik
Rekomendasi: RS yang sudah menggunakan Microsoft 365 sebaiknya memanfaatkan OneDrive + SharePoint untuk konsistensi ekosistem.

Pertimbangan Keamanan Data Pasien di Cloud

⚠ Regulasi: Data kesehatan pasien di Indonesia dilindungi UU No. 17/2023 dan regulasi BPJS. Menyimpan data identitas pasien di cloud publik tanpa enkripsi dan tanpa kebijakan akses yang ketat adalah pelanggaran.
  • Enkripsi: Pilih provider yang mengenkripsi data saat transit (in-transit) dan saat diam (at-rest)
  • Lokasi data center: Preferensi data pasien Indonesia disimpan di server dalam negeri
  • Audit log: Aktifkan pencatatan siapa mengakses file kapan
  • Hak akses minimal: Berikan akses hanya sesuai kebutuhan (principle of least privilege)
  • Two-Factor Authentication (2FA): WAJIB untuk semua akun cloud RS

Kapan menggunakan riwayat versi?
  • Saat isi dokumen diubah secara tidak sengaja dan perlu dikembalikan
  • Saat ingin melihat siapa yang membuat perubahan tertentu dan kapan
  • Saat dokumen melewati beberapa siklus revisi dan perlu dibandingkan
  • Saat ada konflik antara dua versi yang diedit bersamaan

Google Drive menyimpan riwayat versi hingga 30 hari (akun personal) atau unlimited (Workspace). OneDrive menyimpan hingga 500 versi per file.

Tugas Lab

  1. Buat folder bersama di Google Drive (atau OneDrive) dengan nama: 2026-03_Tugas-Lab-P14_[NamaKelompok]
  2. Undang 2–3 anggota kelompok dengan peran Editor
  3. Buat satu dokumen Google Docs / Word Online berisi rekap operasional harian fiktif selama 3 hari
  4. Setiap anggota melakukan minimal satu edit dan lihat riwayat versi
  5. Screenshot riwayat versi dan simpan di folder yang sama

Kriteria penilaian: 1) Folder terstruktur dengan nama sesuai konvensi 2) Hak akses diatur dengan benar (bukan "siapa saja") 3) Ada bukti kolaborasi (min. 2 pengeditan berbeda pengguna) 4) Riwayat versi terdokumentasi

Ringkasan Pertemuan 14

  1. Cloud storage lebih aman dari lokal: backup otomatis, aksesible dari mana saja
  2. Hak akses: Viewer (lihat) → Commenter (lihat+komentar) → Editor (lihat+edit+bagikan)
  3. Data pasien di cloud WAJIB akses terbatas, enkripsi, dan 2FA
  4. Penamaan file: [Tahun-Bulan]_[JenisDoc]_[Unit]_[versi] untuk konsistensi
