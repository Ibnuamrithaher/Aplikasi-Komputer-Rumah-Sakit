Word Lanjutan & Mail Merge

CPMK-1: Mampu mengoptimalkan fitur lanjutan MS Word untuk manajemen dokumen massal RS.

    Doni Prakoso, staf administrasi RS Sehat Citra (fiktif), mendapat tugas besar: mengirimkan 200 surat undangan kontrol ke pasien yang terdaftar. Ia mulai mengetik satu per satu, nama pasien, poli tujuan, tanggal kontrol, nama dokter, di setiap surat. Setelah satu jam ia baru selesai 8 surat. Kepala Administrasi menegur: "Kamu tidak akan kelar minggu ini kalau begitu. Pakai Mail Merge!"

    Mail Merge adalah fitur MS Word yang menggabungkan template surat dengan data dari file Excel/CSV untuk menghasilkan ratusan dokumen personal secara otomatis. Hari ini kita pelajari cara kerjanya dari awal.

    Jawab dulu tanpa takut salah, ini hanya untuk melihat titik awal pengetahuanmu.

    Simulator pembuat tabel Word. Atur jumlah baris dan kolom, lalu isi nama kolom header.

    Klik sel header (baris pertama) untuk mengganti nama kolom. Sel data lainnya juga bisa diedit sebagai latihan.

    Tips tabel di MS Word

    Merge Cell: Pilih sel yang ingin digabung → klik kanan → Merge Cells. Berguna untuk header yang mencakup beberapa kolom.

    Lebar Kolom: Klik kanan pada kolom → Table Properties → Column → atur lebar. Atau seret batas kolom secara manual.

    Warna Header: Pilih baris header → Design (Table Design) → Shading → pilih warna. Gunakan warna yang kontras.

    Sort Data: Klik di dalam tabel → Layout → Sort → pilih kolom dan urutan (A→Z atau Z→A).

    Animasi di bawah menunjukkan bagaimana Mail Merge bekerja. Klik tombol "Proses →" untuk melihat alurnya.

    5 Konsep Kunci Mail Merge

    1. Master Dokumen: File Word berisi template surat dengan placeholder «field».
    2. Data Source: File Excel/CSV berisi daftar penerima (setiap baris = 1 penerima).
    3. Field Name: Nama kolom di Excel harus cocok persis dengan placeholder di Word.
    4. Preview Results: Cek hasil sebelum mencetak, pastikan semua field terisi dengan benar.
    5. Finish & Merge: Hasilkan semua dokumen sekaligus, cetak langsung atau simpan ke file baru.

    Tugas Lab

    Lakukan Mail Merge nyata di MS Word menggunakan file CSV yang diunduh:

    1. Unduh file CSV datasource di bawah.
    2. Buat master dokumen surat undangan kontrol di Word dengan placeholder «Nama», «Poli», «Tanggal», «Dokter».
    3. Hubungkan ke file CSV: Mailings → Select Recipients → Use Existing List.
    4. Sisipkan field: letakkan kursor di posisi yang tepat → Insert Merge Field.
    5. Preview Results → periksa setiap halaman.
    6. Finish & Merge → Print Documents (atau Edit Individual Documents).

    Kriteria penilaian: 1) Master dokumen menggunakan placeholder yang benar. 2) Hasil merge menghasilkan 10 dokumen berbeda. 3) Semua field terisi sesuai data.

    Ringkasan Pertemuan 05

    1. Tabel di Word dibuat dari Insert → Table. Header baris pertama harus diberi format bold dan warna berbeda.
    2. Mail Merge menggabungkan master dokumen (template) dengan datasource (Excel/CSV) secara otomatis.
    3. Placeholder di master dokumen ditulis dengan format «NamaKolom», harus cocok persis dengan header datasource.
    4. Jumlah dokumen hasil merge = jumlah baris data. 10 baris = 10 surat berbeda.
    5. Simpan file Word dan Excel di folder yang sama agar link datasource tidak terputus.
