Perangkat Lunak (Software) & Pemetaan Aplikasi

    Rini baru diterima sebagai staf administrasi di RS Bhakti Medika. Di meja kerjanya ada komputer baru dengan puluhan ikon aplikasi. Ketika atasannya meminta rekap data kunjungan pasien bulan lalu, Rini bingung: apakah harus buka Word atau Excel? Saat mengirim file via email, file-nya 8 MB dan sering gagal terkirim. Temannya menyarankan WinRAR, tapi Rini tidak tahu cara pakainya. Hari ini kita bantu Rini memahami peta aplikasi di komputer RS.

    Setelah pertemuan ini, kalian mampu memilih aplikasi yang tepat untuk setiap tugas administrasi, mengompresi file, dan bekerja dengan PDF secara efisien.

    Jawab berdasarkan pengetahuan awal kalian. Tidak ada nilai negatif.

    Hardware dan software: dua sisi yang tidak bisa dipisah

    Minggu lalu kita membahas hardware, yaitu bagian komputer yang bisa disentuh. Hari ini kita membahas software (perangkat lunak): kumpulan instruksi yang membuat hardware bekerja. Komputer tanpa software hanya seonggok logam dan plastik. Software tanpa hardware tidak punya tempat untuk berjalan.

    Bayangkan sebuah rumah sakit. Gedung, ruang rawat, dan alat medis adalah hardware. Tata kelola, yaitu siapa memakai ruang operasi pada jam berapa, obat disimpan di mana, dan siapa yang boleh masuk ICU, berperan sebagai sistem operasi. Unit layanan seperti pendaftaran, farmasi, dan laboratorium berperan sebagai aplikasi. Satpam, petugas kebersihan, dan teknisi pemeliharaan berperan sebagai utilitas.

    Lapisan komputer (klik tiap lapisan)

    Enam tugas sistem operasi

    1. Mengatur proses (multitasking)
    OS membagi waktu prosesor agar banyak program tampak berjalan bersamaan. Di RS: SIMRS, browser untuk klaim, dan Excel terbuka sekaligus di satu PC loket.
    2. Mengatur memori (RAM)
    OS membagi RAM ke setiap program. Jika RAM penuh, komputer melambat karena terpaksa memakai ruang di penyimpanan. Di RS: terlalu banyak tab dan aplikasi terbuka membuat PC lama terasa lemot.
    3. Mengelola file dan folder
    OS menyimpan nama, lokasi, ukuran, dan tanggal setiap file dalam sistem berkas (di Windows umumnya NTFS). Di RS: penamaan folder yang rapi, misalnya 2026-10_Rekap_Kunjungan, mempercepat pencarian dokumen.
    4. Mengelola perangkat (driver)
    Setiap perangkat perlu driver, yaitu program penerjemah antara OS dan perangkat. Di RS: printer gelang pasien atau scanner barcode tidak akan berfungsi bila driver-nya belum terpasang.
    5. Menyediakan antarmuka pengguna
    GUI memakai ikon, jendela, dan klik. CLI memakai perintah teks. Di RS: staf administrasi memakai GUI, sedangkan administrator server sering memakai CLI.
    6. Menjaga keamanan dan akun
    OS mengatur akun, kata sandi, dan hak akses. Di RS: setiap petugas memakai akunnya sendiri agar tercatat siapa mengubah apa. Berbagi kata sandi menghilangkan jejak itu.

    Jenis sistem operasi yang akan kalian temui

    Paling umum di komputer perkantoran, dan banyak SIMRS dibuat untuk Windows. Versi terbaru saat ini adalah Windows 11. Lisensinya berbayar dan biasanya sudah termasuk di komputer baru.

    Perlu diingat: dukungan Windows 10 berakhir pada 14 Oktober 2025. Komputer yang masih memakainya tidak lagi menerima pembaruan keamanan gratis, kecuali lewat program pembaruan berbayar (ESU).

    Dibuat Apple dan hanya berjalan di komputer Apple (Mac). Populer untuk desain dan produksi media, tetapi jarang dipakai untuk administrasi RS. Contoh versi: macOS Ventura.

    Gratis dan sumber terbuka (open source), tersedia dalam banyak distribusi seperti Ubuntu dan Debian. Umum di server, termasuk server basis data SIMRS, karena hemat sumber daya. Kurang umum di komputer staf karena sebagian aplikasi hanya tersedia untuk Windows.

    Sistem operasi ponsel dan tablet. Di RS: tablet visite perawat, ponsel untuk dokumentasi, dan aplikasi untuk pasien seperti Mobile JKN.

    Utilitas: perawat komputer

    Utilitas adalah perangkat lunak pendukung yang menjaga komputer tetap aman, bersih, dan terawat. Ia bukan alat kerja utama, tetapi sangat menentukan apakah komputer bisa terus dipakai.

    FungsiContohKapan dipakai

    Kompresi7-Zip, WinRAR, folder terkompresi bawaan WindowsMengirim banyak file, membuat arsip
    PembersihanDisk Cleanup, Storage SenseRuang penyimpanan hampir penuh
    Optimasi diskOptimize DrivesPerawatan berkala, defrag hanya untuk hard disk mekanik
    PencadanganFile History, Windows Backup, OneDriveMenyalin file penting secara berkala

    Tiga ancaman yang paling sering

    Virus / malware

    Program berbahaya yang merusak, mencuri data, atau memata-matai. Sering masuk lewat flash disk, unduhan, dan software bajakan.

    Ransomware

    Mengenkripsi file lalu meminta tebusan. Pelindung utamanya adalah cadangan yang tidak ikut terenkripsi.

    Phishing

    Pesan palsu yang meniru pihak tepercaya (misalnya "BPJS") agar korban membuka lampiran atau memasukkan kata sandi.

    Data kesehatan termasuk data pribadi yang bersifat spesifik dalam UU Pelindungan Data Pribadi (UU No. 27 Tahun 2022). Menjaganya adalah tanggung jawab semua petugas, bukan hanya bagian IT.

    Kebiasaan aman setiap minggu

    • Pastikan Windows Security aktif dan definisinya mutakhir
    • Jalankan pembaruan Windows di luar jam pelayanan
    • Pindai flash disk sebelum membuka isinya
    • Jangan membuka lampiran atau tautan dari pengirim yang tidak dikenal
    • Kunci layar (Windows+L) setiap meninggalkan komputer
    • Salin file penting ke tempat lain sesuai aturan 3-2-1

    Simulator pencadangan 3-2-1

    Aturan 3-2-1: 3 salinan data, di 2 jenis media berbeda, dengan 1 salinan di luar lokasi. Centang salinan yang kamu buat, lalu pilih sebuah kejadian.

    Mengapa defrag tidak untuk SSD?
    Hard disk mekanik menyimpan data di piringan berputar, sehingga potongan file yang tersebar memperlambat pembacaan. Defrag merapikannya. SSD tidak punya bagian bergerak, sehingga letak data tidak memengaruhi kecepatan, dan defrag justru menambah keausan. Windows menangani SSD dengan cara lain (TRIM) secara otomatis.

    Mengapa Staf RS Perlu Kompresi File?

    Email RS umumnya membatasi lampiran sekitar 10 MB, sedangkan scan rekam medis satu pasien bisa 5 sampai 15 MB. Kompresi membantu dalam tiga hal: menggabungkan banyak file menjadi satu paket, menghemat ruang pada file yang memang bisa dikecilkan, dan menambah kata sandi bila diperlukan.

    Dua jenis kompresi

    Lossless (tanpa kehilangan)

    Setelah diekstrak, isi file sama persis dengan aslinya. Contoh: ZIP, 7z, RAR. Wajib untuk dokumen dan data RS.

    Lossy (ada yang dibuang)

    Ukuran kecil karena sebagian detail dibuang dan tidak bisa dikembalikan. Contoh: JPEG, MP3. Hati-hati pada citra medis yang butuh detail.

    Cara kerja paling sederhana

    Ketik teks di bawah. Kompresi mencari pola berulang dan menggantinya dengan ringkasan. Ini hanya gambaran ide, ZIP memakai metode yang lebih canggih.

    Simulator Kompresi ZIP

    Atur ukuran file dan pilih jenisnya. Angka rasio hanyalah perkiraan, hasil nyata bergantung pada isi file.

    Cara membuat dan membuka ZIP

    • Kumpulkan file yang akan dikirim dalam satu folder dengan nama jelas
    • Pilih semua file, klik kanan, lalu pilih Send to → Compressed (zipped) folder
    • Beri nama arsip, misalnya Rekap-Oktober-2026.zip
    • Periksa ukuran arsip di File Explorer sebelum melampirkan ke email
    • Untuk membuka: klik kanan arsip, pilih Extract All, lalu tentukan folder tujuan
    • Untuk kata sandi: gunakan 7-Zip (klik kanan, 7-Zip → Add to archive, isi kolom Encryption, pilih AES-256)

    PDF: Portable Document Format

    PDF adalah format dokumen yang tampilannya tidak berubah di perangkat apa pun: komputer, tablet, ponsel, atau printer.

    Kelebihan PDF
    • Tampilan konsisten di semua perangkat dan OS
    • Tidak mudah diedit sembarangan
    • Ukuran relatif kecil dibanding file gambar
    • Mendukung tanda tangan digital
    • Semua orang bisa membukanya tanpa memiliki Word
    Kapan memakai PDF di RS
    • Surat rujukan yang dicetak atau dikirim email
    • Laporan bulanan atau tahunan
    • Formulir pendaftaran
    • Dokumen yang perlu tanda tangan digital
    • Arsip yang tidak boleh berubah

    Beberapa jenis PDF

    JenisCiriContoh pemakaian
    PDF biasaTeks dan gambar yang tampil tetapSurat, laporan
    PDF hasil scanBerupa gambar halaman, teks tidak bisa dicari tanpa OCRScan formulir lama
    PDF/AStandar untuk arsip jangka panjangArsip dokumen administrasi
    PDF bertanda tangan digitalTanda tangan elektronik yang dapat diverifikasi dan menandai bila dokumen berubahSurat keputusan, kontrak

    Menjaga dokumen tetap rahasia

    • Jangan unggah dokumen yang memuat data pasien ke situs gabung, pisah, atau kompres PDF online. Berkas tersimpan di server pihak lain dan Anda tidak mengendalikannya.
    • Redaksi yang benar: kotak hitam yang digambar di atas teks tidak menghapus teks di bawahnya. Pakai fitur Redact pada aplikasi PDF yang mendukungnya, lalu simpan sebagai file baru.
    • Kata sandi PDF: bisa diberikan lewat aplikasi PDF. Kirim kata sandi lewat jalur terpisah.
    • Periksa sebelum kirim: buka PDF final, gulir semua halaman, dan pastikan tidak ada halaman salah pasien.

    Situs online boleh dipakai hanya untuk dokumen umum yang tidak mengandung data pribadi.

    Latihan: Urutkan Langkah Menggabungkan 2 PDF (aplikasi offline)

    Skenario: Anda perlu menggabungkan Surat Rujukan.pdf dan Hasil Lab Pasien A (fiktif).pdf sebelum dikirim ke dokter spesialis. Gunakan aplikasi yang berjalan di komputer, misalnya PDFsam Basic atau PDF24 Creator, bukan situs online.

    Konversi Word → PDF (langkah demi langkah)

    Cara termudah: gunakan fitur bawaan MS Word, yaitu Save As → PDF. Tidak perlu software tambahan.

    • Buka dokumen Word yang sudah selesai diedit dan siap dikirim
    • Klik menu File di pojok kiri atas
    • Pilih Save As (atau Simpan Sebagai)
    • Klik kotak dropdown "Save as type", pilih PDF (*.pdf)
    • Beri nama file yang jelas, misalnya: Surat-Rujukan-PasienA-20261105.pdf
    • Klik Save / Simpan, file PDF tersimpan di folder yang sama

    Alternatif lebih cepat: File → Export → Create PDF/XPS langsung menghasilkan PDF tanpa dialog Save As.

    Mengecilkan PDF hasil scan: turunkan resolusi scan ke sekitar 150 sampai 200 dpi dan pakai mode hitam-putih untuk halaman yang hanya berisi teks.

    Matriks Pemilihan Aplikasi Kantor RS

    Untuk setiap jenis dokumen RS berikut, pilih aplikasi yang paling tepat. Klik pilihan, lalu tekan Periksa.

    Tips Cepat Memilih Aplikasi
    • Word → pertanyaan: "apakah ini teks naratif yang perlu diformat rapi?" → surat, laporan narasi, notulen, SK, berita acara.
    • Excel → pertanyaan: "apakah ada data berulang, angka, atau perhitungan?" → tagihan, jadwal, rekap, inventaris, laporan keuangan.
    • PowerPoint → pertanyaan: "apakah ini akan ditampilkan di layar besar?" → presentasi rapat, penyuluhan, profil RS.

    Rini mendapat tugas pertama: memeriksa komputer di loket pendaftaran RS Sehat Citra. Ia menemukan beberapa hal yang janggal. Pada tiap temuan, pilih tindakan yang paling tepat.

    Kamu adalah staf administrasi baru di RS Sehat Citra. Untuk setiap kartu tugas berikut, pilih aplikasi yang paling tepat: Word, Excel, atau PPT.

    Tugas Lab

    1. Di komputer lab, buka File Explorer → amati aplikasi di folder Program Files. Catat minimal 10 aplikasi dan kategorikan ke tabel: OS / Aplikasi / Utilitas.
    2. Ambil salah satu file Word dari folder Dokumen. Simpan ulang sebagai PDF menggunakan File → Save As → PDF. Tunjukkan ke instruktur.
    3. Buat folder baru bernama Backup_[NIM] di Desktop. Masukkan 3 file dokumen berbeda, lalu kompresikan menjadi satu file ZIP menggunakan klik-kanan → Send to → Compressed folder.

    Kriteria penilaian (dari RPS): 1) Tabel 10 aplikasi benar dikategorikan (40%) 2) File PDF berhasil dibuat (30%) 3) File ZIP dengan 3 file di dalamnya (30%)

    Ringkasan Pertemuan 03

    1. Tiga jenis software: OS (fondasi sistem), Aplikasi (tugas spesifik), Utilitas (perawatan, keamanan, dan manajemen sistem).
    2. Lisensi dan ekstensi: pilih software berlisensi sah, baca ekstensi file sebelum membukanya, dan waspadai file berekstensi .exe yang menyamar.
    3. Keamanan dan cadangan: aktifkan antivirus, perbarui sistem, dan terapkan aturan 3-2-1 untuk data penting.
    4. Kompresi ZIP paling berguna untuk menggabungkan file dan mengecilkan teks, CSV, atau dokumen lama. JPEG dan scan nyaris tidak mengecil. Pakai 7-Zip dengan kata sandi untuk data sensitif.
    5. PDF adalah format dokumen final. Gabungkan dan ubah PDF memakai aplikasi offline, dan jangan unggah dokumen pasien ke situs online.
    6. Word untuk teks naratif, Excel untuk data tabular dan angka, PowerPoint untuk presentasi visual.
    7. Memilih aplikasi yang tepat sejak awal menghemat waktu revisi dan menghasilkan dokumen yang lebih profesional.
