    Excel adalah sumber kebenaran tunggal. Word dan PPT tidak menyimpan data sendiri, semuanya mengambil dari Excel melalui Link. Ubah satu kali di Excel → semua dokumen sinkron.

    12 masalah paling sering terjadi saat mengerjakan proyek administrasi RS terpadu, beserta solusinya.

    Word: format hilang setelah copy-paste dari email

    Solusi: Gunakan Paste Special → Keep Text Only (Ctrl+Shift+V), lalu format ulang menggunakan Style di Word. Hindari paste langsung dari browser/email karena membawa format HTML yang merusak tampilan.

    Excel: #VALUE! error di formula

    Solusi: Periksa apakah ada teks atau spasi tersembunyi di sel yang seharusnya berisi angka. Gunakan fungsi =ISNUMBER(A1) untuk mengecek. Konversi teks ke angka dengan =VALUE(A1) atau klik Data → Text to Columns.

    Excel: #DIV/0! error

    Solusi: Pembagi bernilai nol atau kosong. Gunakan: =IF(B2=0,"",A2/B2) untuk mencegah error ditampilkan. Atau gunakan =IFERROR(A2/B2,0) untuk menampilkan 0 jika terjadi error.

    PPT: font tidak terbaca di komputer lain

    Solusi: Saat menyimpan PPT, gunakan File → Options → Save → Embed fonts in the file. Centang "Embed only the characters used in the presentation" untuk menjaga ukuran file tetap kecil.

    Link putus setelah file dipindah ke folder lain

    Solusi: Di Word/PPT, klik File → Info → Edit Links to Files. Pilih link yang putus → Change Source → navigasikan ke lokasi file baru. Ke depannya, simpan selalu Word/PPT dan Excel dalam satu folder yang sama.

    File terlalu besar untuk dilampirkan di email (>25 MB)

    Solusi: (1) Kompres gambar di Word/PPT: Picture Tools → Compress Pictures. (2) Simpan sebagai PDF untuk pengiriman. (3) Upload ke cloud (Google Drive/OneDrive RS) dan kirim link. (4) Zip dengan kompresi jika memungkinkan.

    Mail Merge tidak menemukan datasource Excel

    Solusi: Pastikan file Excel berada di lokasi yang sama seperti saat pertama kali di-link. Nama sheet Excel tidak boleh berubah. Jika pindah komputer, reconnect melalui Mailings → Select Recipients → Use Existing List.

    Grafik di PPT tidak update setelah Excel diubah

    Solusi: Klik kanan pada grafik di PPT → Update Link. Atau masuk ke File → Info → Edit Links to Files → Update Now. Pastikan file Excel sudah disimpan (Ctrl+S) sebelum kembali ke PPT.

    Tabel Word berantakan setelah diedit

    Solusi: Klik kanan tabel → Table Properties → Column → atur lebar kolom dengan nilai tetap (Fixed). Jangan biarkan Word mengatur lebar otomatis jika tabel harus terlihat konsisten. Gunakan "AutoFit to Fixed Column Width".

    Kontras warna slide terlalu rendah, sulit dibaca di proyektor

    Solusi: Uji kontras dengan tools online seperti WebAIM Contrast Checker. Standar WCAG AA minimum 4,5:1. Kombinasi aman: teks putih di atas biru gelap (#0b7285), teks hitam di atas kuning terang. Hindari merah di atas hijau (tidak aman untuk buta warna).

    Data pasien tersimpan di cloud akun pribadi staf

    Solusi: Data pasien termasuk data sensitif (ITE, UU No.29/2004 tentang Praktik Kedokteran). Wajib disimpan di akun institusi RS (bukan Gmail/personal OneDrive staf). Hubungi IT RS untuk setup akun Office 365 atau Google Workspace institusi.

    Email massal dengan CC terekspos ke semua penerima

    Solusi: Untuk email ke banyak orang, masukkan semua penerima di kolom BCC, bukan CC. Kolom To bisa diisi alamat email RS sendiri. Ini melindungi privasi data kontak penerima dan terlihat lebih profesional.

    3 Pertanyaan Penguji yang Paling Sering Muncul

    ❓ "Mengapa tidak menggunakan format PDF saja untuk seluruh dokumen?"

    Tips Jawaban: PDF adalah format final untuk distribusi dan arsip, tidak bisa diedit, ukuran terkontrol, tampilan konsisten di semua perangkat. Namun Word tetap diperlukan untuk kolaborasi, revisi, dan pembaruan konten di masa depan. Keduanya punya peran berbeda dan saling melengkapi. Dalam proyek ini, kami menghasilkan keduanya: Word sebagai source file yang bisa diedit, PDF sebagai versi final untuk distribusi.

    ❓ "Jika data Excel berubah mendadak, bagaimana memperbarui seluruh paket dokumen?"

    Tips Jawaban: Karena kami menggunakan Paste Link, cukup satu langkah: (1) Perbarui data di Excel dan simpan. (2) Buka Word → klik kanan tabel tertaut → Update Link. (3) Buka PPT → klik kanan grafik → Update Link. Seluruh proses bisa selesai dalam 5 menit, inilah keunggulan integrasi OLE dibandingkan copy-paste biasa.

    ❓ "Kenapa BOR bulan Oktober turun dari 82% menjadi 67%?"

    Tips Jawaban: Siapkan analisis sebelum presentasi! Cek: (1) Apakah ada perubahan jumlah tempat tidur total? (2) Apakah ada penurunan kasus/rujukan karena faktor musiman? (3) Apakah ada pengaruh kebijakan BPJS? (4) Apakah data input sudah benar (tidak ada error input di HIS)? Presenter yang baik sudah mengantisipasi pertanyaan seperti ini dengan menyiapkan "slide backup" yang berisi analisis mendalam.
