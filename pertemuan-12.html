    Checklist Persiapan File Rapat

    • File Excel sumber sudah diisi dengan data terbaru dan disimpan
    • File PPT sudah tersimpan dan link grafik sudah di-update (klik kanan → Update Link)
    • Backup file tersimpan di flash disk dan/atau cloud storage
    • Uji tampilan di proyektor / monitor presentasi sebelum rapat dimulai
    • Font yang digunakan sudah terpasang di komputer presentasi
    • Laser pointer / presenter remote sudah dicek baterainya
    • Print-out cadangan tersedia jika proyektor bermasalah

    5 Etika Live Demo Data di Rapat

    1. Siapkan backup plan — jika link grafik putus, print-out atau PDF cadangan harus tersedia.
    2. Jangan edit data live tanpa konfirmasi — perubahan angka di depan peserta harus disetujui lebih dulu.
    3. Simpan semua file sebelum presentasi — Ctrl+S pada Excel dan PPT, lalu tutup Excel agar tidak ada konflik akses.
    4. Gunakan mode read-only jika memungkinkan — buka Excel dalam Protected View untuk mencegah edit tidak sengaja.
    5. Siapkan print-out cadangan — minimal ringkasan data penting, berjaga jika proyektor atau laptop bermasalah.

    Tugas Lab — PPT + Excel Nyata

    1. Buat file Excel Data_Rapat_Kinerja.xlsx: sheet "Kunjungan" (5 poli, 3 bulan) dan sheet "Keuangan" (pendapatan per poli).
    2. Buat grafik bar dari sheet Kunjungan. Copy grafik tersebut.
    3. Di PowerPoint baru, gunakan Paste Special → Paste Link → Microsoft Excel Chart Object.
    4. Buat juga versi Embed di slide berikutnya. Bandingkan ukuran file PPT sebelum dan sesudah.
    5. Ubah satu angka di Excel, kembali ke PPT, klik kanan grafik linked → Update Link. Verifikasi perubahan.

    Kriteria penilaian: 1) Linked chart berfungsi dan dapat di-update; 2) Embedded chart mandiri; 3) Grafik jenis sesuai data; 4) Slide rapi dan terbaca dari jarak 3 meter.

    Ringkasan Pertemuan 12

    1. Linked chart di PPT selalu sinkron dengan Excel — ideal untuk laporan rutin rapat koordinasi.
    2. Embedded chart mandiri di dalam PPT — ideal untuk dokumen final yang dikirim ke pihak lain.
    3. Pilih jenis grafik sesuai pesan: bar untuk perbandingan, line untuk tren, pie untuk proporsi.
    4. Siapkan backup (print-out/PDF) untuk antisipasi link putus saat rapat berlangsung.
    5. Perbarui link (Update Link) segera sebelum rapat dimulai, bukan saat rapat berjalan.
